NYANG BOTH MANYAL — PORTFOLIO WEBSITE

FILES
- index.html: page content and structure
- styles.css: responsive layout, colours and visual styling
- script.js: mobile navigation, theme switch, reveal effects and contact email

RUN
1. Extract this folder.
2. Open index.html in a browser, or open the folder in VS Code.
3. For a local development server, use the VS Code Live Server extension.

PERSONALISE
- Add your own portrait at images/profile.jpg (create the images folder).
- Update your email, location, social links and project details in index.html.
- The contact form uses mailto and opens the visitor's email app; it does not send messages to a server.
- Skill descriptions and project cards are editable examples. Only claim skills and project work that accurately represent you.

TECHNOLOGIES
HTML5, CSS3 and vanilla JavaScript. Google Fonts are loaded online; system fallbacks are included.
